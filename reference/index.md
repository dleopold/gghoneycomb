# Package index

## Honeycomb plots

The main layer functions for drawing honeycomb waffle charts.
[`geom_honeycomb()`](https://dleopold.github.io/gghoneycomb/reference/geom_honeycomb.md)
is the primary entry point;
[`stat_honeycomb()`](https://dleopold.github.io/gghoneycomb/reference/stat_honeycomb.md)
is available for advanced use with custom geoms.

- [`geom_honeycomb()`](https://dleopold.github.io/gghoneycomb/reference/geom_honeycomb.md)
  : Honeycomb waffle chart
- [`stat_honeycomb()`](https://dleopold.github.io/gghoneycomb/reference/stat_honeycomb.md)
  : Compute honeycomb layout statistics

## Scales and themes

Honey-inspired discrete color scales and a minimal ggplot2 theme
designed to complement honeycomb plots.

- [`scale_fill_honey()`](https://dleopold.github.io/gghoneycomb/reference/scale_honey.md)
  [`scale_color_honey()`](https://dleopold.github.io/gghoneycomb/reference/scale_honey.md)
  : Honey-inspired discrete scales
- [`honey_pal()`](https://dleopold.github.io/gghoneycomb/reference/honey_pal.md)
  : Honey-inspired palette
- [`theme_honeycomb()`](https://dleopold.github.io/gghoneycomb/reference/theme_honeycomb.md)
  : Minimal theme for honeycomb plots

## Hex grid utilities

Internal helpers for hex grid geometry and compactness scoring.
Documented for reference; not exported.

- [`hex-geometry`](https://dleopold.github.io/gghoneycomb/reference/hex-geometry.md)
  : Hex grid geometry helpers
- [`hex-compactness`](https://dleopold.github.io/gghoneycomb/reference/hex-compactness.md)
  : Hex region compactness utilities
